Overview & Obfuscation Levels

The transformer.cpp file utilizes the Tree-sitter C++ parser library to parse C++ source files, inspect their Abstract Syntax Trees (AST), resolve variable and function scopes, and perform safe source-to-source obfuscation across three configurable levels.

Level Name Description
Level 1 Symbol Renaming Renames local variables, function parameters, class data members, and non-overloaded functions to uniform identifiers (e.g., obf_var_N, obf_member_N, obf_func_N).
Level 2 Comment Stripping Includes Level 1 operations, and strips all single-line and multi-line comments by replacing non-newline characters with spaces to preserve line offsets.
Level 3 Literal Transformation Includes Level 1 and 2 operations, and obfuscates integer constant literals into bitwise and arithmetic expressions.

Tree-sitter AST Node Types

The parser evaluates and queries several node types from the C++ Tree-sitter grammar:

Identifiers and Types

  • identifier: General names for variables, function names, and parameters.
  • field_identifier: Names of class or struct member variables.
  • type_identifier: Names of custom types, classes, or structs.
  • primitive_type: Built-in primitive types (e.g., int, double, char).

Declarations and Declarators

  • declaration: Variable or object declaration statements.
  • function_definition: Complete function definition containing a body.
  • function_declarator: Function signature containing parameter list and name.
  • init_declarator: Variable declaration with an initializer.
  • parameter_declaration: Individual parameter in a function or lambda declaration.
  • pointer_declarator, reference_declarator, array_declarator, parenthesized_declarator, attributed_declarator: Wrappers for complex type declarators.
  • abstract_function_declarator, parameter_list: Structural blocks for parameters.

Classes and Structs

  • class_specifier: Class or struct definition block.
  • field_declaration_list: Block containing class member variables and functions.
  • field_declaration: Individual member field declaration inside a class.

Scopes and Expressions

  • compound_statement: Code blocks enclosed within curly braces ({ }).
  • for_statement, if_statement, while_statement: Control flow statements.
  • translation_unit: Root global AST scope of the entire source file.
  • call_expression: Function call expression.
  • field_expression: Member access expressions (e.g., obj.field, ptr->field, or this->field).
  • comment: Single-line or multi-line source code comment node.

8. Main Transformation Driver

transformCppFile

Signature: bool transformCppFile(const std::string& inputPath, const std::string& outputPath, int level, std::string& error)

The main orchestration entry point that handles file I/O, parsing, multi-pass symbol discovery, reference collection, edit generation, reverse-offset sorting, string replacements, comment stripping, literal transformation, and writing output files.

Algorithm Steps inside transformCppFile:

  1. Validates input/output file paths and ensures the requested obfuscation level is between 1 and 3.
  2. Reads the source code binary into memory and initializes the Tree-sitter C++ parser.
  3. Parses the syntax tree and aborts if root syntax errors are encountered.
  4. Discovers local variable candidates, class member candidates, function candidates, and object instances.
  5. Collects all usage references for symbols across their respective scopes.
  6. Generates edit structs and sorts them in descending order of byte start offsets (right-to-left) so preceding byte positions remain accurate during string substitution.
  7. Applies replacements to the in-memory source string.
  8. If level >= 2, calls removeCommentsFromSource().
  9. If level >= 3, calls transformIntegerLiterals().
  10. Writes the final transformed source code buffer to the output file path.
